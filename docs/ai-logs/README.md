# AI augmentation logs

One file per working session: `YYYY-MM-DD-<story-id>.md`. Required for submission (requirement item 9).

## Template

```
# Session: <story ID> - <date>
- Agent / subagent used:
- Model:
- Prompt (verbatim or link):
- What the agent produced:
- What I accepted, changed or rejected, and why:
- Verified by (command, file or reviewer):
- Agent errors or gaps found:
```

Rules: log what actually happened, including failures. Do not backfill from memory later than the same day.
